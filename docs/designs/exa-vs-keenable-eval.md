## Accepted Scope (added to this plan)
- Query source: Model Diplomat MongoDB, exported into the customer-log columns, stratified by task class.
- Arms: Exa (as Model Diplomat calls it today) vs Keenable search+fetch (baseline A) and SELECT (B, C).
- Judge: blind, both orders, ties on flip; agreement with Karl's labels shown on the report.
- End-to-end: ~50 tasks replayed through the agent per provider; final answers judged.
- Dollars: full trace cost (search, rerank, fetch, context tokens), not the search line alone.
- Outputs: win/match rate with CIs and dollars per correct row by class; downloadable loss file (missing URLs = crawl list).
- Live SELECT editor on screen B.
- Hosted URL with redaction and password-gated live paths.
- Router consuming the per-class table, live immediately, kill switch + Exa fallback (D8).
- Swap point: Keenable ToolSeam beside `model-diplomat/search` harness/providers/exa_tools.py.
- Metric: correct row = judge says arm supports a correct answer; match = Keenable correct when Exa correct; headline = match rate + $ per correct row by class.
- Order (no deadline): export, B+live SELECT, judge+C, replay, URL, router.
- Proposed defaults (task class, miss labels, CIs, SELECT translation, judge model, redaction, trace dollars) are listed in the working plan as pending owner confirmation.
