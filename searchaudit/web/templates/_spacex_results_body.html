Final thoughts

Some limits hold whatever the grades say. SELECT takes minutes, which is fine for a memo and too slow for chat. SELECT is the only column with a usage note, so its result is the tool plus the note. Jev can send a table prompt to search, or a one-page prompt to SELECT; that is a routing miss, not a search miss.
